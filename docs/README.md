# docs

Top-level docs hold only **cross-module content**: strategy and the
publications that span modules. Everything module-specific lives in the
module (`<module>/docs/` - articles, evidence, lessons), per the
[graph placement rules](../sdlc/GRAPH.md#placement-rules).

| Directory | Content |
|-----------|---------|
| [strategic/](strategic/) | Direction: DIRECTION.md, strategic packages, research |
| [adr/](adr/) | Repo-shaping architecture decision records |
| [projects/](projects/) | Cross-module project publications: whitepapers spanning modules |
| [weekly/](weekly/) | Weekly publications: digests in short-book form (CTO and CEO audiences) |

Process lessons live with the process: [sdlc/docs/lessons/](../sdlc/docs/lessons/).
