# D-twins

Digital twins: seem-to-real and real-to-seem environments. 2D/3D/4D simulation engines
and an engine-under-your-engine layer.

- Runs as a containerized service with autoscale and startup/shutdown orchestration via
  API and command line; operable by agents.
- Gated environment spin-up via API and command line; demoable via pixel streaming inside Meet.
- Experimental environments: an Unreal Engine sample environment and MuJoCo-type
  physics environments.
