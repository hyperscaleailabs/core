# Meet

LiveKit / SFU based video conferencing system with pluggable LiveKit agents.

- Public surface with approved sign-up.
- Generalist voice agent plugged into rooms via the agents subproject.
- Pixel streaming integrated into the same browser session, used to demo d-twins
  environments inside a call.
