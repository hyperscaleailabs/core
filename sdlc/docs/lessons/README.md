# Lessons learned

One file per review round or merge: `YYYY-MM-DD-<slug>.md`. Each lesson states
the correction, the lesson, and where it is now codified (CI guard, LIFECYCLE
update, or skill update). Written via the `lessons` skill; aggregated into
Atlas white papers. People are referred to by role.

Lessons are part of the [SDLC](../../README.md) - its upward signal.
Lessons are included in each project's
[article](../../LIFECYCLE.md#project-shape); articles aggregate into the
[daily deck and whitepaper](../../DAILY.md), dailies into the
[weekly digest and monthly architecture review](../../TACTICAL.md), and the
aggregate reaches the [strategic checkpoints](../../STRATEGIC.md). An
unread lesson is an open loop.
